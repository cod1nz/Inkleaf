# Inkleaf feature list

Inkleaf ships every tool listed here as a page in the offline desktop build. The list is generated from
`src/js/config/tools.ts`, the same file the web app uses, so it only names tools that exist there.

- **118 distinct tool pages** across **7 categories** (see `docs-desktop/stats.json`).
- Categories overlap on purpose: a tool can appear in more than one (for example, Merge PDF is in both
  Popular Tools and Organize & Manage). The per-category counts below therefore add up to more than 118.
- Tool names are shown as they appear in the app. Each one opens its own page; nothing is uploaded.

Tool names in the lists below are the labels from `tools.ts`. The command palette (Ctrl/Cmd+K) and the
home screen both search this catalogue.
